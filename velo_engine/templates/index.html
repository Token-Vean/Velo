Esta fase proyecta los hallazgos confirmados sobre la imagen del PDF original. Las cajas negras se calculan con la misma base textual u OCR empleada para el análisis. Es el paso previo obligatorio antes de aplicar la edición sobre el original.

Aplicación sobre el original

Este es el quinto paso del proceso para PDF. Aquí Velo genera una copia derivada editada del PDF original, aplicando las redacciones sobre la imagen de cada página a partir de la misma base textual u OCR usada en la detección.

Exportación

Verificación antes de exportar
La copia exportada no modifica el original fuente fuera de la sesión. El informe JSON deja traza de revisión. Si se ha aplicado la edición sobre el original, la descarga corresponde a una copia derivada visual del PDF original ya redactada.
ISO/IEC 27038: la copia visual rasteriza las páginas y materializa máscaras negras. El expurgo nativo elimina el contenido subyacente en las zonas confirmadas y conserva la capa de texto del resto del PDF.
ISO/IEC 20889: el informe conserva la técnica seleccionada para cada hallazgo, aunque la materialización visual del PDF original se realiza como tachado gráfico.
